# AI Adoption — KPIs, Outcomes & Measurement

***

## Enterprise Agentic AI
Sales Admin + Accounting (MTM) • Bottom-Up Adoption

### <mark>What We Will Do</mark>
* UC1: Sales Order capture (email/Excel → context → SAP SO)
* UC2: Payment Reconciliation (E-banking stmt → match → ERP update)
* Evaluate: OpenClaw, n8n, Power Automate, UiPath, MS AI Studio

### <mark>Expected Outcome</mark>
* End-to-end order capture + payment reconciliation automated
* Manual data entry, credit-check, and stock-release steps eliminated
* Agents handle context that rigid RPA/workflow cannot

### <mark>How to Measure</mark>
* Orders + reconciliations processed via agent vs. manual baseline
* Error rate and processing time: before vs. after deployment
* User adoption: # of teams onboarded (bottom-up approach)

***

## Dev Team AI Workflow
Proof of Progress • GitHub Copilot Enterprise • 150+ Team

### <mark>What We Will Do</mark>
* Proof of Progress: morning to-do → evening update via GitHub
* AI monitors: Backlog → Progress → Stuck (≥3 days = alert) → Hand off
* Cancel ClickUp by M6; force migration to GitHub Copilot Enterprise

### <mark>Expected Outcome</mark>
* Real-time visibility: burnout, idle, and stuck detection across all roles
* 100% of PM, PO, BA, Dev, Arch, QA reporting via single system
* Management allocates resources based on live AI-analyzed data

### <mark>How to Measure</mark>
* Daily active users on GitHub Copilot Enterprise (vs. current low adoption)
* Avg time stuck items detected and resolved: before vs. after
* ClickUp fully decommissioned by M6; 100% team migration
